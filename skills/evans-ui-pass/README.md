# evans-ui-pass

[![skills.sh](https://skills.sh/b/Archetypically/skills)](https://skills.sh/Archetypically/skills)

Evan's UI pass: the design iteration method distilled from his own
corrections across web builds, kept current by a learning loop that folds
every new nudge back into the skill.

A pass is not done when the page looks better. It is done when the named
skills actually ran (installed files read and applied, never briefed from
memory), the Hallmark audit gate closed at 0 FAIL with every waiver named,
contrast was measured on the rendered pairs in both color schemes, and the
report says per skill what changed and what was not verified.

The taste rules in one breath: real photography over drawn scenes, system
light/dark with no toggle, frosted glass at high opacity, no pills,
no grain overlays (a photograph dithered as itself is a treatment, not
an overlay), no random glows, totals as badges by the header and metadata in
a footer, hierarchy that reads at a glance, and color that means one thing
everywhere it appears.

## Install

```bash
npx skills add Archetypically/skills --skill evans-ui-pass
```
