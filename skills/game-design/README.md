# game-design

A design-review lens for games. It judges a mechanic, system, enemy, boss rule or economy change against a five-part framework (feeling, goals, decisions and opposition, rules and theme, interaction), then goes past the framework into randomness and fairness, dominant strategies, economies, clarity, motivation, accessibility and dark patterns. Every proposal gets scored on ten axes, and playtest findings get a fixed reporting shape.

## Install

```
npx skills add Archetypically/skills --skill game-design
```

## What is inside

- `SKILL.md` — the lens itself: the framework, the research extensions, the evaluation scorecard, and the playtest and post-mortem method.
- `references/research.md` — the research the second half distils: GDC talks, peer-reviewed papers, established books, designers' own writing and accessibility guidelines, each source tagged by how far it was verified (read in full, metadata only, secondhand, or bibliographic record).
