# x-virality

[![skills.sh](https://skills.sh/b/Archetypically/skills)](https://skills.sh/Archetypically/skills)

Engineer virality on X. A skill that plans a launch or announcement post so people quote it, share it, and keep the conversation going long after it posts.

## Who it is for

Founders and teams launching a product on X who want the post to travel further than their own followers.

## Install

With the [skills CLI](https://www.skills.sh/docs):

```
npx skills add Archetypically/skills --skill x-virality
```

Any agent that reads `SKILL.md` files can use it. To use it by hand, copy this folder into your agent's skills directory.

## What it does

- Shapes the post around specifics a stranger can add to, instead of a bare announcement.
- Builds several angles from one post and matches each angle to a person whose experience fits it.
- Splits coverage of replies, quote posts, and comments across the team, and logs the questions that keep coming up.
- Judges the wave by trials, messages, and sales calls rather than views.
- Plans the follow-up wave from what the first one produced.
