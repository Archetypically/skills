# skills

Agent skills I have made and distilled. Each folder under `skills/` is a self-contained skill in the open agent skills format: a `SKILL.md` an agent reads to learn a method.

## Install

With the [skills CLI](https://www.skills.sh/docs):

```
npx skills add Archetypically/skills --skill x-virality
```

## Skills

| Skill | What it does |
| --- | --- |
| [x-virality](skills/x-virality/SKILL.md) | Engineer virality on X. Plan a launch or announcement post so people quote and spread it: quotable specifics built into the post, different angles matched to the right sharers, team coverage of the response, and a second wave planned from the results. |
