# skills

Agent skills I have made and distilled. Each folder under `skills/` is a self-contained skill in the open agent skills format: a `SKILL.md` an agent reads to learn a method.

## Install

With the [skills CLI](https://www.skills.sh/docs):

```
npx skills add Archetypically/skills --skill x-virality
```

## Skills

| Skill | What it does |
| --- | --- |
| [evans-ui-pass](skills/evans-ui-pass/SKILL.md) | Run a design iteration pass the way Evan demands: the installed skills run for real, contrast is measured not estimated, the Hallmark audit gate closes with every waiver named, and his taste rules hold — real photography, system light/dark, honest frosted glass, no slop tells, hierarchy at a glance, color as a language. Self-improving: every new nudge gets distilled back into the skill. |
| [game-design](skills/game-design/SKILL.md) | Judge a game design before you build or tune it: name the feeling it targets, check goals and pacing at every timescale, audit decisions, dominance, randomness, economy and accessibility, and score proposals on ten axes. Built on Riot's URF Academy framework plus a cited body of modern design research. |
| [x-virality](skills/x-virality/SKILL.md) | Engineer virality on X. Plan a launch or announcement post so people quote and spread it: quotable specifics built into the post, different angles matched to the right sharers, team coverage of the response, and a second wave planned from the results. |
